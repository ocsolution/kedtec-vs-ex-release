# Privacy Policy for OC Developer Mode

Last updated: October 31, 2026

## What data we collect

OC Developer Mode does not collect any personal data, browsing history or page content.

## What the extension stores

The extension stores one setting on your device: whether developer mode is ON or OFF. This setting is kept in the extension's local storage and is never synced or sent anywhere.

## Cookies

While developer mode is ON, the extension adds a developer-mode cookie to the websites you open, so that sites that support OC Developer Mode can turn developer mode on. While it is OFF, the extension removes that cookie. The cookie contains only a developer-mode key that changes every day; it does not contain any information about you. It is a session cookie, so the browser deletes it when Chrome closes.

## Third-party services

This extension does not use any third-party services, analytics or tracking.

## Data sharing

We do not sell, share or transfer any data. The extension makes no network requests of its own.

## Data retention and deletion

The ON/OFF setting is reset to OFF every time Chrome starts and is removed when you uninstall the extension. You can remove the developer-mode cookie at any time by turning developer mode OFF or by clearing cookies in Chrome.

## Changes to this policy

If the extension's data practices change, we will update this policy and the "Last updated" date above.
